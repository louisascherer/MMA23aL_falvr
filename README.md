# FLAVR – Kräuter- und Gewürzshop

Schulprojekt (Modul M291) der Klasse MMA23aL: ein kleiner Webshop für den
fiktiven Gewürzshop **flavr**, umgesetzt mit PHP und einer MariaDB-Datenbank
auf einem Plesk-Server.

> Das ist ein Schulprojekt und keine reale Website.

## Gruppenmitglieder

- Leonie Walker
- Louisa Scherer (Plesk-Verantwortliche)
- Olivia Vieli

## Technik

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP mit PDO und Prepared Statements
- **Datenbank:** MariaDB / MySQL
- **Hosting:** Plesk-Server

## Seiten

- `index.php` – Startseite mit Bestseller-Slider, Glücksrad und Gewinnspiel
- `shop.php` – Produktübersicht mit Kategorie-Filter und Warenkorb
- `produkt.php` – Produkt-Detailseite
- `erlebnisse.php` – Gewürzerlebnisse
- `ueber-uns.php` – Info-Seite über flavr
